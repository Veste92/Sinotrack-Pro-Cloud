SinoTrack Pro Cloud

A custom integration for Home Assistant that connects compatible SinoTrack GPS trackers through the SinoTrack cloud service.

Features

* Connect to your SinoTrack cloud account.
* Add compatible GPS trackers to Home Assistant.
* Expose tracker location data through Home Assistant.

Installation via HACS

1. Open HACS in Home Assistant.
2. Open the three-dot menu and choose Custom repositories.
3. Add https://github.com/Veste92/Sinotrack-Pro-Cloud.
4. Select Integration as the category.
5. Find SinoTrack Pro Cloud in HACS and download it.
6. Restart Home Assistant.
7. Go to Settings → Devices & services → Add integration.
8. Search for SinoTrack Pro Cloud and follow the setup prompts.

Configuration

You will need a compatible SinoTrack tracker and the account details requested by the integration.

Enter your credentials through the Home Assistant integration setup flow. Never publish your password, tracker ID, or access tokens in issues or screenshots.

Troubleshooting

* Confirm your tracker and SinoTrack cloud account are working.
* Check Home Assistant logs for errors related to sinotrack_pro_cloud.
* Verify your account details and internet connection if the integration cannot connect.
